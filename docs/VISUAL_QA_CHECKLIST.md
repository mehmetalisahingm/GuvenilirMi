# Visual QA Checklist

- [ ] Hero headline and device share the first viewport without overlap at 1440px.
- [ ] URL field remains readable at 1280px, 1024px and mobile widths.
- [ ] Floating signal cards never cover primary CTA or score content.
- [ ] Scroll story changes environment tone for safe / danger / deep states.
- [ ] Laptop base and screen remain visually connected at all breakpoints.
- [ ] Reduced motion disables continuous scan and decorative movement.
- [ ] Source cards expose year and source label.
- [ ] Live analysis page uses the same visual language as landing.
- [ ] Risk state never names a real business in the synthetic demo.
- [ ] Product copy does not claim certification or absolute safety.
